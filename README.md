# Paga Yang Portfolio

Static portfolio site prepared for GitHub Pages. No build step or external JavaScript dependencies are required.

## Publishing

Upload every file and folder in this package to the root of the `bobobbie/Portfolio` repository. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The public URL will be `https://bobobbie.github.io/Portfolio/`.
